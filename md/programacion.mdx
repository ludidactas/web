# Programación

Para familiarizarte con la esencia de este tema a nivel absolutamente fundamental, te invito a jugar (y pasar!) el siguiente juego:

- [Compute-it](https://compute-it.toxicode.fr/), de Toxicode.

- Una vez hecho esto, vas a tener las bases para entrar con confianza a [Scratch](https://scratch.mit.edu/). No lo desestimes, porque si bien es un lenguaje visual, es muy poderoso.

- Luego, te recomiendo que sigas con [EduBlocks](https://edublocks.org/), un entorno que te va a permitir traducir bloques a código Python, para empezar a familiarizarte con cómo luce el código posta.

- Finalmente estás en pie para empezar a programar en Python o Javascript. Para eso, te recomiendo [el curso de Ludidactas](#), por supuesto. 

Cuando entiendas cómo usar variables, bucles, condicionales, funciones, listas, diccionarios y sets, vas a estar en condiciones de seguir adelante por la vía que vos quieras.
